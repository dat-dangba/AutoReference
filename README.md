# Auto-Reference Toolkit

The Auto-Reference Toolkit is a Unity editor extension designed to simplify the process of retrieving, validating,
and assigning references to assets or components during edit time.

[View documentation](https://zoodinger.gitlab.io/autoreference/index.html)

[Quick reference cheat sheet](https://zoodinger.gitlab.io/autoreference/cheatsheet.html)

## Installation Process

Install this package through the Unity Package Manager:

1. Open **Window ▸ Package Manager**
2. Click the **+** sign in the top-left corner and select **Add package from git URL...**
3. Enter the repository URL:
    ```text
    https://gitlab.com/zoodinger/autoreference.git
    ```
   To install and stay on a specific version, append the version tag:
    ```text
    https://gitlab.com/zoodinger/autoreference.git#v2.3.1
    ```
4. Click **Add** to complete the installation.
